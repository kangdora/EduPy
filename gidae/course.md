# 기초 데이터
## 단원 설명
기초 데이터 수업과 관련된 내용이고, 대표적 파이썬 **외부** 라이브러리인
- NumPy
- pandas
- matplotlib
- SciPy
- scikit-learn 

에 대해 학습해봅시다.

---
## 과정 설명
- basicNumPy.py - 수치 계산 라이브러리 NumPy의 배열과 벡터 연산을 익히는 단계입니다.
- basicPandas.py - pandas의 데이터프레임과 시리즈를 활용해 데이터 처리와 분석을 연습합니다.
- basicMatplotlib.py - matplotlib을 사용해 선 그래프, 막대 그래프 등 시각화를 연습합니다.
- basicSciPy.py - SciPy의 수치 해석 기능을 통해 선형대수, 최적화, 신호처리 등을 경험합니다.
- basicScikitLearn.py - scikit-learn을 사용하여 머신러닝 모델 학습과 평가를 익힙니다.
